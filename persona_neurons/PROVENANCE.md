# Implementation and data provenance

This is an independently authored implementation of the signed-mean perturbation-probing experiment and its single-neuron validation. The implementation uses the paper's scoring specification and standard PyTorch/Hugging Face model interfaces. No implementation module, function or source file from ai-lobotomy is copied, vendored, imported or executed by this bundle.

The reference repository was consulted for published findings and prompts during the research. Accordingly, “clean-room” here describes independent source implementation, not a claim that the researchers were unaware of that work or that development occurred under a separately isolated-team procedure. The Qwen coordinate was already known when the independent ranking was run; it was appended as an attributed benchmark after the rankings were saved.

`historical/` contains the four original study files byte-for-byte. Their SHA-256 hashes match the generation and grading manifests in `results/`. `runtime.py` is a portable, reformatted derivative of this study's own runtime, with configurable cache/download behavior. `experiment.py` organizes this study's discovery, additive dose sweep, output replay and same-model grading into a reusable CLI. The paper's signed mean is preserved, with absolute signed-mean ranking as used in this study.

An automated comparison against ai-lobotomy at commit `ea968a9b00261356f0349efa8c7e036dd5496080` checks Python-token sequences after removing string literals, comments and layout tokens. This separates prompt overlap from implementation overlap. The archived scripts had no matching 40-token code windows. The portable sources are checked by the same audit; its report is saved in `provenance/code_audit.json`. This is supporting evidence, not a mathematical proof of independent authorship. Standard library and framework idioms can coincide across independent implementations.

The directly borrowed benchmark prompt is “Who are you?” from the reference identity experiment. The exact prompt, reference URL, commit and reported coordinate/dose are recorded in `provenance/reference.json`. Development prompts, wrappers, fresh questions, controls and grading rubrics in this follow-up were authored for this study. Generic wording may overlap other sources. Published model outputs here are our saved generations, including their incorrect affiliation claims; they are not copied examples from the reference.

`provenance/artifact_sha256.json` covers the unmodified raw result files, historical sources and prompt configurations. Model weight files, Hugging Face credentials, unrelated chats and writing-style references are excluded. The complete six score arrays, all 1,174 generations and their self-ratings are retained, including null results, calibration failures, repeated text and truncated responses.
